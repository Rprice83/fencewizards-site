How it works

From first call to pickup, in five steps.

99% of our work is business-to-business, so the process is built around a project manager who needs a number for a bid and a date to hold a sub to.

  1. 1

    Tell us five things

    Location, fence style, linear feet, number of gates, and how long you need it.

  2. 2

    Get a number same day

    Verbally first, because you need it for a bid. The written proposal follows.

  3. 3

    We schedule the install

    24–48 hours is normal. Emergency work moves faster.

  4. 4

    We stay reachable

    Gate needs to move or a run added? Call and we come out — same day for GCs.

  5. 5

    We pull it on your schedule

    Not ours, and not for an extra fee. Removal was in the number.
